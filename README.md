# Road-Accident-Dashboard
Road Accident Dashboard

This project is an interactive Power BI dashboard developed to analyse road accident data and present the information in a clear and accessible way. The dashboard was created to turn the underlying accident data into visual insights that make it easier to understand accident patterns, casualties and the factors surrounding road accidents.

The project focuses on using Power BI to move from raw data to an interactive reporting experience. The dashboard brings the available accident information together in one place and allows the information to be explored visually rather than relying on rows of raw data.

I developed the dashboard as part of my data analytics and business intelligence work, with particular attention to data preparation, visualisation and presenting information in a way that can support analysis and decision-making.

The final dashboard is presented through interactive Power BI visuals, with the different views designed to make patterns within the accident data easier to identify. The project demonstrates my ability to work with Power BI as an end-to-end analytics and reporting tool, from working with the underlying dataset to building the final dashboard.

The Power BI source file is included in this repository as `Road Accident Dashboard.pbix`, while `road-accidents-screenshot/dashboard.png` provides a preview of the completed dashboard.
